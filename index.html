Ongoing

Embedded Cybersecurity Anomaly Detector

IoT security · On-device ML

An embedded cybersecurity anomaly detector designed to monitor CAN bus communication and identify abnormal or potentially malicious messages in real time. The system uses an autoencoder-based machine learning model trained on normal CAN traffic to detect deviations from expected communication patterns. My contribution focuses on the ML component, including data preprocessing, feature extraction, autoencoder training, reconstruction-error analysis, and anomaly-threshold determination. The trained model is intended to work alongside STM32-based CAN nodes to detect anomalies such as message injection or abnormal motor-related behavior.
